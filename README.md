## Overview

Laundry Management System is a full-featured web application that streamlines laundry business operations. It provides an intuitive interface for customers to place orders, track laundry status, and make payments, while empowering administrators with comprehensive management tools and automated workflows.

---

## Features

### Customer Features
- User registration and authentication
- Profile management
- Order creation with service selection
- Laundry type and weight input
- Pickup scheduling
- Real-time order tracking
- Order history
- Online payment integration (Midtrans)
- Payment confirmation

### Admin Features
- Interactive dashboard with statistics
- Customer management
- Courier management
- Order management
- Service and pricing management
- Promo management
- Payment management
- Order status management
- Revenue reporting
- Data export

### Courier Features
- Pickup task management
- Delivery task management
- Pickup status updates
- Delivery status updates

### Automation Features (n8n)
- WhatsApp chatbot integration
- Automated status notifications
- Invoice delivery
- Payment reminders
- Pickup reminders
- Order confirmation
